👁️ About NetraSenseAI

NetraSenseAI is an AI-powered eye disease screening & vision assessment platform designed to help users perform basic eye screening from anywhere. It combines traditional vision tests with deep learning-based disease detection.

🧠 EfficientNetB0🎯 91% Accuracy⚡ Flask👁️ 5 Diseases📦 TensorFlow

🎯 Objectives

  • Provide instant basic vision screening
  • Detect eye diseases using AI (EfficientNetB0)
  • Increase awareness of eye health
  • Encourage early medical consultation

⚙️ Technologies Used

PythonFlaskTensorFlow / Keras EfficientNetB0OpenCVHTML5CSS3JavaScript

Model: EfficientNetB0 fine-tuned on 2000+ eye images
Params: 7.7M • Accuracy: 91% • Classes: 5

✨ Features

  • Visual Acuity Test (Snellen)
  • Color Vision Test (Ishihara)
  • Contrast Sensitivity Test
  • AI Disease Detection (5 diseases)
  • Smart Vision Report
  • Personalized Eye Care Tips

👨‍⚕️ How It Works

1. User registers & logs in securely
2. Performs vision tests in browser
3. Uploads eye image for AI analysis
4. Gets instant prediction with confidence
5. Downloads personalized report

Built for Impact: Early screening → Early treatment

⚠️

Medical Disclaimer

NetraSenseAI is intended only as a screening tool. It does not replace diagnosis by a qualified ophthalmologist. Our AI model has 91% accuracy but users should always consult an eye specialist for proper medical evaluation. Early detection saves vision.
