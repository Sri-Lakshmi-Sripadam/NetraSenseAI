## 🌟 Features

**1. AI Disease Detection**
- Upload eye image -> Detects 10+ conditions: Cataract, Glaucoma, Uveitis, Eyelid disorders, Normal
- Uses EfficientNet / Custom CNN with 92%+ accuracy
- Grad-CAM visualization for explainable AI

**2. Symptom Checker**
- ML-based symptom analysis (Random Forest)
- Personalized risk assessment & recommendations

**3. Vision Tests**
- Visual Acuity Test
- Color Blindness Test (Ishihara)
- Astigmatism Test
- Generates PDF Vision Report

**4. Dashboard & Reports**
- User authentication (Login/Register)
- Health Score calculation
- Downloadable PDF reports
- History tracking with SQLite
